## 💡 About CivicLens

**CivicLens** is a next-generation AI-powered Civic Intelligence Platform built to help citizens understand the problems affecting their local communities.

Every day, communities face challenges such as damaged roads, water shortages, poor drainage, waste management problems, pollution and inadequate public infrastructure.

But how many citizens actually understand why these problems happen, which authorities are responsible, or how they can take action?

**CivicLens aims to change that.**

By combining Artificial Intelligence, geographical intelligence, public information and community participation, CivicLens creates a unified digital platform where citizens can discover, understand and engage with local civic issues.

# 🚀 Getting Started

### Prerequisites

- Node.js LTS
- npm
- Git
- VS Code or another code editor

### 01 — Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CivicLens.git
```

### 02 — Navigate into the project

```bash
cd CivicLens
```

### 03 — Install dependencies

```bash
npm install
```

### 04 — Configure environment variables

Create `.env.local` in the project root.

```env
GEMINI_API_KEY=your_gemini_api_key

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_publishable_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

NEXT_PUBLIC_MAP_STYLE_URL=your_map_style_url

NEXT_PUBLIC_APP_URL=http://localhost:3000
```

Use the exact environment variable names required by your implementation. Keep secret credentials server-side and never commit `.env.local`.

### 05 — Start the development server

```bash
npm run dev
```

### 06 — Open CivicLens

```text
http://localhost:3000
```

# 🛡️ Transparency, Privacy & Trust

Trust is at the heart of CivicLens.

We distinguish between different sources of civic information.

| Information type | Meaning |
|---|---|
| 📝 Citizen Submitted | Information provided by citizens |
| 🤖 AI Generated | AI-generated explanations |
| 🔍 Independently Verified | Independently checked information |
| 🏛️ Officially Published | Published by government sources |
| ✅ Officially Confirmed | Confirmed through an authorized process |

Our principles:

- Responsible AI usage.
- Privacy-first architecture.
- Secure citizen authentication.
- Transparent information sources.
- Consent-based location access.
- Reliable civic information.
- Secure evidence management.
- Clear verification processes.

**CivicLens is an independent civic information platform and does not claim to represent or operate on behalf of any government authority.**
